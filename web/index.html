AgentTether

AI agents buy blockchain event watches with x402: the agent signs one Permit2 voucher (worst case = the quoted ceiling), a Substreams stream meters the blocks actually processed, and settlement is pro-rata — exactly the blocks billed, delivered to the agent's webhook only after the settlement receipt confirms.

Ask your agent

Give your coding agent (opencode, Claude Code, …) a prompt like:

"Using the AgentTether API at http://localhost:8080, watch Ethereum mainnet USDC
for any transfer ≥ 1,000 USDC for the next 60 seconds. Pay for it yourself with x402
(your agent wallet is already Permit2-approved), then report what arrived."

The agent negotiates the 402, signs the voucher, waits for the webhook, and hands you back a link like …/w/<intent-id> — this site renders what happened: the watch, the delivered events, and the settlement receipt.

Try it without an agent

Point the report page at any intent id: /w/<intent-id>. The API must be reachable from your browser — when the backend runs locally, open the page through the backend itself (http://localhost:8080/w/<id>); when this page is hosted, pass the backend base as ?api=https://your-tunnel….

Data velocity on Ethereum mainnet; x402 settlement on Base Sepolia (or Hedera testnet) — different chains by design. See the repo README for the full architecture and the per-block billing model.
